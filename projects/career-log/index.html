Overview

A web journal where a user writes a short note about what they did and how it felt. The app structures it, suggests what to read next, recommends postings and lays out a checklist to each deadline.

Shown at
2026 Codex Community Korea Hackathon, Team03
Method
OpenAI structures each note into experience, activity, reaction and reason
Ran on
Docker Compose on AWS EC2

Problem define

"A one-off aptitude test tells you little." The team's view was that a long record of small experiences tells more.

Solution

A Spring Boot service with a calendar, an AI note analysis and reference and posting suggestions. The schedule and daily checklist are rule-based, so they cost no API calls.

Process

  1. Backend. The Spring Boot project, login API, database and CareerNote API were set up on 2026-08-16.
  2. Structure. Each note is sent to OpenAI and stored as experience, activity, reaction and reason.
  3. Plan. Recommended postings become a calendar entry with a rule-based daily checklist up to the deadline.
  4. Deploy. A Dockerfile and compose.yaml bundle the app and PostgreSQL for EC2.

Lesson

Postings and references come from seeded demo data, not a live source. Three demo postings with example.com links are loaded at startup, so recommendations are drawn from those three. The repo holds no test with users.
