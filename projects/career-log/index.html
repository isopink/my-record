Overview

A web journal where a user writes a short note about what they did and how it felt. The app structures it, suggests what to read next, recommends postings and lays out a checklist to each deadline.

It is a Spring Boot service with a calendar, AI analysis of each note, and reading and posting suggestions; the schedule and the daily checklist are rule-based, so they cost no API calls. The backend, login API, database and CareerNote API were set up on 16 August 2026. Each note goes to OpenAI and comes back as experience, activity, reaction and reason, and a recommended posting becomes a calendar entry with a daily checklist up to its deadline. A Dockerfile and compose.yaml bundle the app with PostgreSQL for EC2.
