Overview

A Claude skill that takes one paper or a bundle of 2 to 5 and builds a full review talk. Out come a manuscript, HTML, PDF and PPTX decks, reproduction plots and a speaker script.

Data
arXiv papers via alphaXiv MCP, with web search as fallback
Method
literature notes, reproduction ladder L1 to L4, deck build, render check
Coverage
example 28-page, three-paper Sim2Real talk (SPI-Active, ASAP, FADA)

Solution

A skill that reruns or rebuilds each paper's core idea and states which claims were reproduced. It also checks every deck for overflow, overlap and broken images before it ships.

Key Process

  1. Notes. Each paper gets a literature note and a numbers file rechecked against the full text, not the abstract.
  2. Reproduce. With no GPU, reduced toy versions of all three papers were run on a 2-core cloud CPU.
  3. Checkpoints. Evaluating FADA's released checkpoints was stopped: the needed model and data were unreleased and IsaacSim needs CUDA. A toy reproduction replaced it.
  4. Check. render_check.py found overflowing tables on p.8, 13 and 18; slides were re-laid out over three passes.
